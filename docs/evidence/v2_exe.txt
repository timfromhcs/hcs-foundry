The browser rendered the onboarding screen from the bundled SPA
(`.playwright-mcp/exe-onboarding.png`).

## Notes

- Data defaults to `%LOCALAPPDATA%\HCS Foundry` so the executable can sit in a read-only folder.
- The executable picks a free port if the preferred one is taken.
- Fine-tuning is unavailable in the executable because the ML stack is excluded; the UI reports that instead of failing silently.
